# 🚀 Quick Deploy Guide

Get your Weather Dashboard live in 5 minutes!

## Step 1: Push to GitHub

```bash
# Initialize git (if not already done)
git init

# Add all files
git add .

# Commit
git commit -m "Weather Dashboard - Ready to deploy"

# Create main branch
git branch -M main

# Add your GitHub repository
git remote add origin https://github.com/YOUR_USERNAME/weather-dashboard.git

# Push
git push -u origin main
```

## Step 2: Deploy to Vercel

1. Go to **[vercel.com](https://vercel.com)**
2. Click **"Sign Up"** (use GitHub account)
3. Click **"New Project"**
4. Select your **weather-dashboard** repository
5. Click **"Deploy"**
6. Wait 1-2 minutes ⏱️
7. **Done!** 🎉 You'll get a URL like: `https://weather-dashboard-xyz.vercel.app`

## That's It!

Share your URL with anyone - they can now use your weather dashboard!

---

## Alternative: GitHub Pages (100% Free)

If you prefer GitHub Pages:

1. Push to GitHub (Step 1 above)
2. Go to your repository on GitHub
3. Click **Settings** → **Pages**
4. Under **Source**, select **"GitHub Actions"**
5. Wait 2-3 minutes for automatic deployment
6. Your app will be live at: `https://YOUR_USERNAME.github.io/weather-dashboard/`
